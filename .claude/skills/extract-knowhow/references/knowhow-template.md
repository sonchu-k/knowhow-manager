```markdown
# 見積もりは複数案を並べて提示する

## 要点

範囲の異なる複数案を並べて提示すると、相手の判断が「受けるか断るか」から「どれを選ぶか」に変わり、合意に進みやすい。

## 状況

どんな場面で使えるか。前提となる条件。

## やり方

具体的に何をするか。手順や判断基準があれば箇条書きで。

## なぜ効くか

仕組み・理由。ここが書けないものは、ノウハウではなく単なる出来事の可能性が高い。

## 注意点・当てはまらない場合

逆効果になる条件、限界、未検証の点。
```

## 各項目

- `title`: 行動や判断が分かる形にする(「見積もりについて」ではなく「見積もりは複数案を並べて提示する」)。
- `category`: `knowhow/` 直下のフォルダ名と一致させる。
- `source_type`: 元資料の**種類**だけを書く(議事録、チャットログ、提案書、振り返りメモなど)。ファイル名や案件名は書かない。
- `evidence_count`: このノウハウを裏付けた資料の数。別の資料で同じ知見が得られたら増やす。1のものは「一度そうだった」に過ぎないと読める。
- 「状況」「注意点」は、該当する内容がなければ省略してよい。「要点」と「なぜ効くか」は必須。
